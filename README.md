# Sujal Shrestha Portfolio (React + Three.js)

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in /dist
```

Edit all content in `src/data/cv.js` (add your project links in the `projects[].link` fields).
Stack: React 18, Vite, @react-three/fiber, three, framer-motion.
